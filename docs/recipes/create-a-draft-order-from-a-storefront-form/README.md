# Create a draft order from a storefront form

Let customers send their cart with a storefront form. Mechanic connects the form and webhook to a task that creates a draft order for your team to review. Place the form on your cart page. This does not send an invoice or reproduce checkout pricing.

This template sets up connected forms and tasks together. Individual tasks remain available separately.

## Included resources

- Cart form submissions (webhook)
- Request a quote from your cart (form)
- [Create a draft order from a storefront form](https://tasks.mechanic.dev/create-a-draft-order-from-a-storefront-form) (task)

## Installation

For a supported form workflow, choose Use this form in Forms or preview its task in the Mechanic library and choose Install this task. Both paths create an unpublished form draft and open one task setup screen. Set the task name, Enabled state, options, and form questions, then choose Save task and publish form. If approval is requested, complete it, return, and choose Save again. Place the published form in your theme and test it. Reopen the same task to edit its setup; do not install another copy. Private files and other custom templates use the configure/review/connect importer, which creates drafts and disabled tasks.

## Updates

A template is a starting point. Template changes apply to future setups and do not overwrite your forms or connections. Recognized library tasks use the existing task-update process and eligibility checks; this does not update the whole setup.
